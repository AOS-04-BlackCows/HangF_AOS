# 📌 예약 시스템 프로젝트 - HangF

## 🔍 프로젝트 개요
본 프로젝트는 부산 용호동과 해운대에 위치한 반찬가게 "힐링쿡"에서 예약 시스템의 필요성을 느껴 개발을 시작했습니다. 이후 기획 점검을 거쳐, 단일 매장이 아닌 다양한 업체에서 활용할 수 있는 범용적인 예약 애플리케이션을 개발하는 방향으로 확장하였습니다.

## 🛠 개발 환경
- **개발 언어**: Kotlin (MVP 단계에서는 Jetpack Compose를 사용하며, 이후 Kotlin Multiplatform으로 업그레이드 예정)
- **서버**: Firebase

## ⚙ 기술 스택
- **네트워크 통신**: Retrofit
- **UI 구성**: Jetpack Compose
- **서버 연동**: FireBase ( Ktor - 보류 )
- **이미지 로딩**: Coil
- **멀티플랫폼 지원**: Kotlin Multiplatform - 보류

## 🎯 주요 기능

### ✅ 고객용 기능
- **예약 등록**: 사용자가 원하는 날짜와 시간에 예약을 등록할 수 있습니다.
- **예약 조회 및 수정**: 기존 예약을 확인하고 필요 시 수정할 수 있습니다.

### ✅ 업주용 기능
- **예약 관리**: 매장의 예약 목록을 조회하고 수정할 수 있습니다.
- **매장 정보 관리**: 매장 정보를 등록 및 수정할 수 있습니다.
- **메뉴 관리**: 매장에서 제공하는 메뉴를 추가, 수정, 삭제할 수 있습니다.

## 📱 지원 플랫폼
- Android 버전 우선 출시 후 iOS 및 웹 플랫폼으로 확장 예정

## 🔔 알림 시스템
- 카카오 알림 및 문자 메시지를 통한 예약 알림 기능 제공

## 📌 향후 계획
프로젝트 진행 상황에 따라 추가 기능을 도입하고, 지속적인 업데이트를 통해 사용자 경험을 개선할 예정입니다.
